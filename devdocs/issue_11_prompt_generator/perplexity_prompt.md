## Reusable fiction prompt generator

Use this to generate a fresh story prompt:

1. Choose core elements

- Genre: [e.g., “science fiction,” “political thriller,” “alternate history,” “character-driven fantasy”]
- Subgenre / flavor: [e.g., “first contact,” “court intrigue,” “hard SF,” “near-future surveillance state”]
- Tone: [e.g., “darkly comic,” “hopeful but tense,” “grim,” “whimsical”]
- Length target: [flash / short story / novelette / novella / novel]
- POV: [first person / close third / omniscient / epistolary]
- Setting seed: [time + place, e.g., “post-Reconstruction U.S.,” “Martian colony,” “Pennsylvania small town”]

1. Define the dramatic core

- Protagonist: [role + flaw + desire, e.g., “disgraced policy analyst who desperately wants to prove one last theory”]
- Antagonistic force: [person / system / environment / self, e.g., “opaque algorithm that allocates citizenship tiers”]
- Central conflict: “[Protagonist] must [do X] before [stakes] happen, but [complication].”

1. Add a speculative or thematic twist

- Speculative hook: [e.g., “AI that can read constitutional intent,” “time travel limited to written documents,” “memories traded as futures contracts”]
- Thematic question: “What happens when [theme tension, e.g., ‘security always wins over liberty’]?”

1. Assemble the prompt

Now combine it all into 3–5 sentences like this:

“Write a [LENGTH] [GENRE/SUBGENRE] told in [POV] with a [TONE] tone.
The story is set in [SETTING].
The protagonist is [PROTAGONIST DESCRIPTION], who wants [DESIRE], but faces [ANTAGONISTIC FORCE].
The speculative hook is [SPECULATIVE HOOK].
Explore the question: [THEMATIC QUESTION].
Begin in medias res as [OPENING MOMENT].”

Fill in [OPENING MOMENT] with a concrete scene starter, e.g., “they discover a redacted clause that should be impossible to exist,” “the colony’s oxygen rations suddenly drop for no documented reason.”
